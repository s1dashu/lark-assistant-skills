# Data Gap Handling

Do not add a fixed "data sources" section to final outputs. Users usually do not need a source inventory in routine reports.

Use source and gap tracking internally to judge confidence. Mention a gap only when it materially changes the conclusion, for example:

- Missing notes for a key meeting.
- A high-stakes report lacks OKR access.
- A project has no visible updates after a specific point.
- A configured source was skipped because of privacy boundaries or permissions.

Never fabricate continuity. If a project abruptly stops in the data, state the discontinuity naturally in the relevant section.
